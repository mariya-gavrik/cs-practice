рабочая папка - где можно видеть и править файлы
индекс - промежуточная зона,куда добавлять изменения перед коммитом
коммит - сохраненная "точка" истории с изменениями и сообщением

Git и GitHub: в чем разница.
Git - это локальная система контроля версий (работает на компьютере, хранит историю, ветки, коммиты)
GitHub - это хостинг для репозиториев (место, где ты публикуешь свой Git-репозиторий, чтобы делиться им и работать в команде)

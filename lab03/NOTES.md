Чем отличается git diff от git show и git log:

git diff показывает разницу (изменения) между рабочей директорией, индексом или коммитами. Обычно используется для просмотра еще не закоммиченных правок.

git show показывает полную информацию о конкретном коммите: метаданные (автор, дата, сообщение) и сам diff (изменения), которые были внесены этим коммитом.

git log показывает историю коммитов в хронологическом порядке.

Что нашли log -S и blame:

git log -S"def" ищет коммиты, в которых количество вхождений строки "def" изменилось. Он показал, в каком коммите впервые появилась функция def main().

git blame показывает, кто и в каком коммите последний раз менял каждую конкретную строку файла. Это помогает найти автора конкретной строки кода

Чем git restore отличается от git restore --source=...:

git restore отменяет изменения в рабочей директории и возвращает файл к состоянию из последнего коммита (HEAD).

git restore --source=  берет версию файла из указанного коммита (например, HEAD~2) и помещает её в рабочую директорию.

Что произошло бы с вашими правками: Если бы у вас были несохраненные правки в файле, команда git restore безвозвратно удалила бы их, так как она перезаписывает рабочую директорию данными из истории.
